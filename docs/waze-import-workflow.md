# Waze Import Workflow

The verified v1 import workflow is still pending.

Until the import spike is complete, assume Waze custom voices are created through the in-app recorder:

1. Open Waze.
2. Go to `Settings > Voice and sound > Waze voice > Add a voice`.
3. Record each prompt.
4. Test the custom voice during navigation.

Future scripts should export clips and checklists to make this manual process easier.
