How the hell does this work?

Waze has no API for custom voices, so the voice-pack format was reverse-engineered from real packs.

  1. 43 filesA pack is exactly 43 MP3s with fixed names. Get one wrong and Waze ignores it silently.
  2. The schema1500.mp3 means "one mile", not 1.5 km. Confirmed by transcribing real packs.
  3. The voiceEvery line rewritten in character, then spoken by a voice model.
  4. NormalizeEvery clip matched to −16 LUFS so nothing jumps out at you mid-drive.
  5. ValidateSqueezed under Waze's undocumented ~0.8 MB cap and checked file by file.
  6. Ship itUploaded to Waze, downloaded back, and verified byte for byte.
