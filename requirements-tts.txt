# Optional: the synthesis step.
#
# Chatterbox (Resemble AI) is the default backend: zero-shot voice cloning from
# roughly ten seconds of reference audio, MIT licensed including the model
# weights, so anything you produce with it is yours to use commercially.
#
#     python -m pip install -r requirements-tts.txt
#
# This pulls in PyTorch, a multi-GB download. It runs on CPU; for a GPU build,
# install torch from https://pytorch.org/get-started/locally/ first.
#
# Synthesis is entirely optional. Without it the pipeline still runs, and any
# phrase your source media does not contain is listed in the export checklist
# for you to record by hand.
